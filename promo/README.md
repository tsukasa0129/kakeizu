# 家系図クエスト 広告ビデオ（モーショングラフィック）

`kakeizu-ad.mp4` — 縦型 1080×1920 / 30fps / 32秒（BGM・効果音つき）。SNS 広告・ストアのプレビュー向け。

| 秒 | シーン |
| --- | --- |
| 0–3.4 | フック「あなたのひいおじいちゃんの名前、言えますか？」 |
| 3.4–7 | ロゴ：ネッコ登場「家系図づくりを、ゲームみたいに。」 |
| 7–13 | STEP 1 戸籍を撮るだけ → AI が人物・続柄・生年月日を読み取り |
| 13–18.6 | STEP 2 家系図が自動で埋まる（XP・曾祖父母コンプリート） |
| 18.6–23.6 | STEP 3 役所ナビで迷わない（本籍地・広域交付・コンビニ/郵送・次の戸籍） |
| 23.6–27.6 | 連続記録・レベルアップ・バッジ |
| 27.6–32 | CTA「あなたのルーツをたどる冒険へ。」 |

## 作り直し方

```bash
cd promo
npm install
python3 music.py          # music.wav を生成（numpy が必要。すべてコードで合成＝著作権フリー）
node render.mjs           # ad.html を1フレームずつ描画して kakeizu-ad.mp4 に書き出し（ffmpeg が必要）
```

- `ad.html` をブラウザで開くとリアルタイムでプレビューできます。
- 文言・タイミングは `ad.html` の `SC`（シーン区間）と各 `renderS*` 関数で調整できます。
- `FRAMES="0,120,300" node render.mjs` で指定フレームの静止画を `stills/` に書き出します。
